# Fomo Live Feed v0.4.0 Release and Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the completed floating-window experience as v0.4.0, add it to the existing website demo and release history, then merge, package, push, and publish the verified release.

**Architecture:** Keep the extension implementation unchanged except for release metadata. Extend the static website's existing generic tab system with one additional semantic panel, using the current design tokens and responsive rules; keep release documentation and download URLs synchronized with the package version.

**Tech Stack:** TypeScript, React 19, WXT/Chrome Manifest V3, static HTML/CSS/JavaScript, Node test runner, Vitest, Playwright, pnpm, GitHub CLI.

---

## File map

- `package.json`, `pnpm-lock.yaml`: authoritative package version.
- `CHANGELOG.md`: bilingual v0.4.0 release record.
- `README.md`: current installation download and feature instructions.
- `website/index.html`: visible version labels, fourth demo tab, FAQ, and release history.
- `website/styles.css`: display-mode demo presentation and responsive behavior.
- `website/main.js`: v0.4.0 download URL; existing generic tab controller remains unchanged.
- `website/homepage.test.mjs`: static website release and accessibility contracts.
- `.output/releases/`: generated ZIP and checksum; never committed.
